# 衡石 · 值班切主演练沙盘
衡石数据值班组（10人）把节点巡检、故障剧本与切主证明合并为可复核演练记录。

## 业务与模块
原流程用值班表记录节点、聊天传递故障、人工比较日志。痛点：输入版本混乱、隔离证明缺失、决策无法复查。上游是巡检记录；本工具替代人工纸上演练；下游是复核人和运维值班负责人。模块为节点状态、故障剧本、演练队列、决策证据、事务恢复，配套登录及JSON导出。四个实体 Node / Scenario / Drill / TxDrill 全链路实现。

**边界：受控教学/运维演练计算模型，不连接真实复制集群、不执行真实生产选主；任期、日志位置和fencing均由用户输入声明。** 本题真实 MySQL 保存业务输入/快照/结果，Python 实际计算规则，后台 worker 异步处理。

## 一天剧本
09:00操作员登录；09:05核对hs-primary日志8100、hs-east日志8100、hs-west日志8098，任期均6；09:10创建shift-20261117剧本，允许损失0、新任期门槛7、主故障且已隔离；09:20提交晚班演练；09:25查看候选hs-east、新任期7、多数派2/2；09:30导出JSON；09:35运行“缺少隔离证明”案例，应阻断；09:40观察员复核但新增返回403；10:00管理员查看 /api/audits。10:10操作员进入事务恢复页，演练切主窗口协调失联：txn-1001在shard-a/b/c准备3条写入，并发2条（txn-2001争用acct:1被拦、txn-2002照常）；选“晚班隔离演练”剧本、裁决commit、补送1次；10:15查看恢复证据：时间线、等待写入、各分片同结局、幂等核查；10:20改用“缺少隔离证明”剧本复跑，切主阻断、事务保持待决；10:25取消“裁决已落盘”复跑，观察裁决未明时仅争用写入被拦。

## 算法口径
输入为入队时冻结的节点与剧本快照。法定票数 floor(配置投票节点数/2)+1；可达票扣除不可达/已隔离/本次故障主节点；候选必须可达、有投票权、非主、未隔离且落后量不超过允许日志损失。新任期=max(节点任期)+1。所有安全条件成立时按日志位置降序、节点名升序确定候选；缺少旧主fencing、票数不足、未触发故障、任期不足或无合格候选均阻断。空节点、零投票节点、多个主节点计算失败并保存原因。结果含输入SHA256与模型版本，可重复计算。不会伪造真实集群共识证据。

事务恢复口径：快照冻结节点、故障剧本、事务准备写入、并发写入与裁决事件。协调失联且裁决未明期间，仅争用同一（分片, 记录）的写入被拦截等待，其余照常执行。切主沿用原选主规则，未放行则事务保持待决、争用写入继续等待。裁决以（事务, 新任期）唯一落盘；切主与裁决并发到达时，全分片读同一份落盘记录，一起提交或回滚。落盘后中断从该记录续跑，不重新裁决、不重复准备；补送裁决按（事务, 任期）去重，重复写入为零。结局含时间线、等待写入、各分片结局与核查证据，模型版本 txn-recovery-v1。

## 工程
|组件|技术|
|---|---|
|前端|原生HTML/CSS/JS模块，Nginx1.27|
|后端|Python3.11/FastAPI/SQLAlchemy/PyJWT|
|任务|MySQL持久队列 + Redis worker互斥锁 + 心跳|
|存储|MySQL8.0、Redis7|
所有计算和权限检查在后端。JWT有效8小时，密码PBKDF2-SHA256 180000轮随机盐。20条待处理任务配额。审计保存业务写入动作；错误返回request-id。五服务均真实健康检查。

目录：frontend/src/api、stores、types、components/common、hooks、pages、router、utils、constants；backend/src/routes、controllers、services、models、schemas、middlewares、utils、constants、config；backend/scripts；backend/migrations。本地开发：安装backend/requirements.txt并设DATABASE_URL、REDIS_URL、JWT_SECRET，再运行uvicorn；前端以Nginx代理/api/去除前缀。

环境：COMPOSE_PROJECT_NAME控制隔离命名；FRONTEND_PORT/BACKEND_PORT/DB_PORT为端口；DB_PASSWORD为演示数据库密码；JWT_SECRET为签名密钥；SEED_DEMO=false关闭演示数据。命名卷db-data、redis-data、artifacts；reset时显式down -v删除数据。前端字体依赖Google Fonts，离线回退serif/sans-serif。模型是简化安全门禁，非完整Raft实现。MIT许可。

枚举：角色在backend/src/constants/enums.py和frontend/src/constants/enums.js；任务状态同处定义，使用于models/entities.py、services/drill_service.py、worker.py、components/common/status.js；节点角色在schemas/node.py、pages/nodes.js；事务恢复结局TX_DECISIONS同处定义，使用于services/recovery.py、pages/tx.js、pages/txdetail.js。测试、截图与已知差异见批次test-artifacts/gb-4110/TESTING.md。
